# Jak 3: The Cinematic Legacy source

This source tree contains the Jak 3 builder and its required shared helpers. Game assets and the OpenGOAL engine are supplied by your supported local installation.

Use the repository scripts in `tools/` to verify and package this source. `source-files.json` lists the developer source archive and the smaller runtime source set separately. The launcher calls the selected module in `game-config.json`.
